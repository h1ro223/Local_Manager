斬鬼

～ 百鬼夜行 ～

釘を抜け、鬼を斬れ。
一撃の大当りと百鬼討滅RUSHを目指す、和風ダークファンタジーのパチンコ。

  • 玉貸で玉を借りて、ハンドルを回すと玉が発射されます
  • 通常時は左打ちでヘソ(START)を狙ってください
  • 音が出ます。音量は設定から変更できます

    遊び方

    基本の流れ

    玉貸で玉を借り、ハンドルを回すと1分間に100発のペースで玉が発射されます。通常時は左打ちで盤面左側に玉を流し、中央下のヘソ(START)に入ると図柄が回転します。図柄が揃えば大当りです。

    玉の通り道は打ち出しの強さで変わります。弱めは道釘を転がるルート、中くらいはワープからステージへのルートに入りやすくなります。強すぎると右側へ流れるので注意してください。

    スペック

    右打ち

    大当り中とRUSH・時短中は右打ちです。玉がスルーゲートを通ると電チューが開き、電チューへの入賞で図柄が回転します。大当り中は下のアタッカーが開きます。

    演出の見どころ

    保留やセリフ、カットインの色は 白 → 青 → 緑 → 赤 → 金 の順に期待度が上がります。虹色は大当り確定です。対決する敵は 天狗 → 大蛇 → 九尾 → 酒呑童子 の順に強敵になり、強い敵ほどチャンスです。擬似連、ステップアップ、群予告、鬼面ギミックの落下、激熱、全回転にも注目してください。

    操作

    スマホハンドルをドラッグして強さを調整(押している間だけ発射)。自動発射で押しっぱなし不要。◀▶で微調整
